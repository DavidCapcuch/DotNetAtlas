# 🔗 External Resources

</div>

Books, articles, talks, and tools that inspired DotNetAtlas and can help you learn more.

## 📚 Books

### Architecture

| Book | Author | Why Read It |
|------|--------|-------------|
| **Clean Architecture** | Robert C. Martin | The foundational text on dependency rules and layer organization |
| **Domain-Driven Design** | Eric Evans | The original DDD book; essential for understanding tactical patterns |
| **Implementing Domain-Driven Design** | Vaughn Vernon | Practical DDD implementation with code examples |
| **Patterns of Enterprise Application Architecture** | Martin Fowler | Classic patterns including Repository, Unit of Work |

### Distributed Systems

| Book | Author | Why Read It |
|------|--------|-------------|
| **Designing Data-Intensive Applications** | Martin Kleppmann | Deep dive into distributed systems, messaging, and data |
| **Enterprise Integration Patterns** | Hohpe & Woolf | Messaging patterns that underpin event-driven architecture |
| **Building Microservices** | Sam Newman | Practical guidance on service boundaries and communication |
| **Release It!** | Michael Nygard | Stability patterns: circuit breakers, timeouts, bulkheads |

### .NET Specific

| Book | Author | Why Read It |
|------|--------|-------------|
| **C# in Depth** | Jon Skeet | Deep understanding of C# language features |
| **Dependency Injection in .NET** | Mark Seemann | DI principles and patterns |
| **Concurrency in C# Cookbook** | Stephen Cleary | Async/await patterns and best practices |
